# BharatCode English fork on upstream 1.9.65

This source incorporates upstream dsh-cost-meter 1.9.65 (bcdf730df1fdb50eb2de2a2cdc62f69e8a763629), with the preserved local API-equivalent estimate configuration, request-start DeepSeek peak/off-peak pricing, historical totals and subscription-spend isolation. The package is @arzvaak/bharatcode-cost-meter 1.9.65-english.20261114.rc3.1. Existing license, upstream source history and contributor attribution are retained.

The main browser factory changed substantially since the local 1.9.39 base. Custom UI now uses a separate package-local client.custom.js chunk through the existing require.async and page-loader contracts. The upstream actual-spending pill remains; an explicitly labeled API-equivalent estimate and peak/off-peak breakdown appear below it. The Cost overview includes the historical total/recalculate card, and Pricing → catalog includes the explicit estimate editor. Recorded ledger amounts and prices are not overwritten by estimates.

This is an English distribution: the main client resolves English and ships its English message dictionary. Full upstream Chinese translations remain in readable source. This preserves the local English behavior while keeping the main asset below the Harness 262144-byte bound. Defaults preserve USD display, exact price matching, hidden official balance, and the local disabled promotional notices/quota queries. Existing configuration still takes precedence.

Verification against built DeepSeek Harness 0.2.2-rc.3: reproducible full build; 30 custom tests; real host/client Typert codec-loader agreement; 19 targeted upstream regression scripts covering ledger recovery/locking/workers/currencies, historical price performance, official-sync currency protection, provider peak schedules, custom balances, custom model prices, accounts, billing history, native search, price revisions, display currencies, multipliers and model repricing. Upstream fixtures for currency and package identity were made explicit for this fork.

Commands: DSH_SOURCE=/path/to/built/harness node --import ./test/resolve-host.mjs scripts/build.mjs; DSH_SOURCE=/path/to/built/harness npm run test:custom. A complete upstream monolithic npm test is not claimed: it currently stops at a Chinese-label assertion in clinepass-quota.mjs, which conflicts with the retained English interface. Browser smoke of the staged full profile is performed separately.
